# Personal Portfolio

A simple personal portfolio site built with Vite, React, TypeScript, and plain CSS. The page is a single landing screen with placeholder text you can replace.

## Install

```bash
npm install
```

## Run the site

Start the development server:

```bash
npm run dev
```

`npm start` does the same thing:

```bash
npm start
```

Open the local URL printed in the terminal. By default that is [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
```

The built files are written to the `dist` folder.

Preview that build locally:

```bash
npm run preview
```

Open the local URL printed in the terminal. By default that is [http://localhost:4173](http://localhost:4173).

## Edit the starter page

- Placeholder text for your name, introduction, projects, and contact link is in `src/App.tsx`.
- Navigation labels are in the same file.
- Color, typography, spacing, and content width are the CSS variables at the top of `src/index.css`.
