# Type scale

Measured from `surinder.design/saga/case` at 1440 and 390 wide. Size / line height / weight.

| Role | Font | Desktop | Phone (under 810px) |
|---|---|---|---|
| Page title | Fraunces | 44/48/500, -0.3px | 32/40/500 |
| Section title | Fraunces | 24/28/500, -0.3px | Same |
| Column title | Fraunces | 28/34/500, -0.3px | Same |
| Big figure | Fraunces | 28/34/500, -0.3px | 24/30/500 |
| Chapter intro | Geist | 18/28/400, soft | 16/24/400 |
| Section text | Geist | 16/24/400, soft | Same |
| Lead statement in a card | Geist | 18/28/600 | Same |
| Body in a container | Geist | 15/23/400 | Same |
| Tight list, such as card bullets | Geist | 15/20/400 | Same |
| Name or title in a card | Geist | 15/20/600 or 15/22/600 | Same |
| Label | Geist | 13/18/500, soft | Same |
| Small text, source or note | Geist | 13/18/400, soft | Same |
| Pill or tag | Geist | 13/13/500 | Same |
| Play button | Geist | 13/24/500 | Same |
| Fine print in a card | Geist | 12/16/400 | Same |
| Red alert mark | Geist | 10/10/700 | Same |
| Step code | Departure Mono | 13/24/400 | Same |
| Stamp | Departure Mono | 11/11/400, +0.22px | Same |
| Nav number | Departure Mono | 12/18/400, +0.3px | Same |
| Code and file names | JetBrains Mono | 12/20/400 or 13/20/400 | Same |
| Nav item | Geist | 15/22/500, detail 13/18/400 | Same |
| Button | Geist | 15/23/500 | Same |

Prototype screens use the reference's larger step copy: title Fraunces 32/40/500, text Geist 20/30/400. The lock screen clock is Geist 56/56/300.

## Spacing

| Gap | Desktop | Phone |
|---|---|---|
| Title to its text | 8px | 8px |
| Lines of a chapter opening | 12px | 12px |
| Text to container | 18px | 18px |
| Container to container | 24px | 24px |
| Section to section | 64px | 40px |
| Chapter opening to first section | 76px | 52px |
| Last section to Next button | 64px | 40px |
| Next button: divider to button | 16px | 16px |

## Controls

The case study's arrow buttons, theme toggle and close button match the landing nav button: 47px on desktop, 38px on phones, with a 44px tap area.
